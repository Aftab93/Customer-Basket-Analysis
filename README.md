# Customer Basket Analysis Project

## Overview

This project analyzes customer shopping basket behavior by combining basket transaction data with customer profile data. It includes data cleaning, merging, exploratory data analysis, visualization, customer segmentation, feature engineering, outlier detection, and a simple machine learning model.

## Features

- Import and prepare datasets
- Merge customer and basket records
- Analyze shopping patterns by gender and age group
- Visualize trends and relationships
- Monthly sales analysis
- Customer segmentation (VIP, Regular, New/Occasional)
- Efficiency score calculation
- Outlier detection using boxplot
- Linear Regression prediction model

## Project Structure

- `Customer_Basket_Analysis.ipynb` — Main Jupyter Notebook
- `README.md` — Project documentation
- `basket_details.csv` — Basket transaction dataset
- `customer_details.csv` — Customer profile dataset

## Technologies Used

- Python

- Matplotlib

- Jupyter Notebook

## How to Run

1. Install Python 3.x
2. Install required libraries:
   ```bash
   pip install pandas numpy matplotlib seaborn scikit-learn notebook
   ```
3. Place the CSV files in the project folder.
4. Open the notebook:
   ```bash
   jupyter notebook
   ```
5. Run all cells.
